# thai-learn-audios
Repositório para armazenar os áudios das palavras tailandesas.

# Como adicionar áudios

- Abra o arquivo `generate-thai-audio-free.mjs`
- Dentro da variável `WORDS`, adicione a palavra e a pronúncia
- Salve o arquivo
- Rode o comando `node generate-audio.mjs`

Obs: lembre-se de manter o `package.json` e, caso não tenha, rode o comando `npm install google-tts-api`.
